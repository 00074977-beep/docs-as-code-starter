# Docs-as-Code

## Project Description
A simple web-site to practice: 
- Issues
- Documentation
- Pull Requests


## Installation and Setup
To get this project up and running:
&downarrow;

1. Use your IDE editor to Clone the repository locally via the terminal:
   ```
   git clone https://github.com/gwenbleiddd/docs-as-code-starter
   ```
  

## Usage

- Open the page in a browser.
- Use “Click me” button to update the status text below displaying both current time button clicked verification.

  #### To use the mini API example 
  1. Open the developer console (right-click &rightarrow; Inspect &rightarrow; Console).
  2. In the console type
     &downarrow;
  
  ``` 
  window.fakeApi.ping("hello")
  ```
  
## Contribution Guidelines



- **Use Issues for new features**
    - Every new feature or major change must be created as an Issue first.
    - Please Include a clear description of the feature as well as  expected behavior.


- **Pull Requests**
    - Submit a Pull Request from your branch to the main branch.
    - If your Pull Request resolves an Issue, include the keyword 'Closes' followed by the issue number in the Pull Request description.
    &downarrow;
      ```
      Closes #<issue-number>
      ```
      This automatically closes the linked Issue when merging takes place.
