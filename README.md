# Sample Web Project

This project demonstrates a simple web application.

## How to set up the project
Follow along to have the project run in your own IDE.

1. **Open your terminal (or command prompt)**  
   - On Windows: search for "Command Prompt" or "PowerShell"  
   - On Mac: open "Terminal"

2. **Copy the URL from the browser**  
   - It would look like this:  
     ```
     https://github.com/RaviTancoo/docs-as-code-starter
     ```

3. **Clone the repository**  
   - In the terminal, type:  
     ```
     git clone https://github.com/RaviTancoo/docs-as-code-starter
     ```  
   - Hit Enter. This will download the project to your computer.

4. **Go into the project folder**  
- `cd` stands for **Change Directory**. It lets you navigate into the project folder.

5. **Open your editor**  
- Open your code editor and select the folder you just navigated to.  
- You should see `index.html` inside.  
- Right-click `index.html` → select **Open with Live Server** (if using VS Code) to open it in your default browser.
