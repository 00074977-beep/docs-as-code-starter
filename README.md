# Docs-as-Code Starter

## Project Description
This project is a small static web application built with HTML, CSS, and JavaScript. 

## Installation and Setup
1. Clone or fork the repository.
2. Open the project folder.
3. Open `index.html` in any modern web browser.

No additional dependencies are required.

## Usage
- Open `index.html` in your browser.
- Click the **“Click me”** button to update the status text.
- Open the browser console to view log messages.
- Run the following demo API command in the console:
  ```js
  window.fakeApi.ping("hello")
## Contribution Guidelines
This project uses GitHub Issues and Pull Requests to manage changes.

- All new features, bug fixes, or documentation updates must begin with a GitHub Issue.
- Each issue should be completed in its own branch (e.g., `docs/readme-update`).
- Changes must be submitted through a Pull Request.
- Pull Requests that resolve an issue must include `Closes #issue-number` in the description.
- Direct commits to the `main` branch are not allowed.
